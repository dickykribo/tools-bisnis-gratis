JSON dan CSV itu dua bahasa data

JSON adalah bahasanya aplikasi dan API — rapi untuk mesin, tapi susah dibaca kalau datanya besar dan bersarang. CSV adalah bahasanya spreadsheet — gampang dibuka di Excel, gampang dihitung, tapi tidak bisa menyimpan struktur bersarang. Hampir semua kerja data sehari-hari adalah pindah dari satu bahasa ke bahasa lain: ekspor dari aplikasi (JSON) lalu olah di Excel (CSV), atau sebaliknya — data tabel dari Excel diubah jadi JSON untuk dimasukkan ke aplikasi. Tool ini mengerjakan pindah bahasa itu dua arah, plus merapikan JSON yang berantakan, tanpa datamu keluar dari browser.

Pertanyaan yang sering ditanya

Apakah dataku diunggah ke server?

Tidak. Semua yang kamu unggah, tempel, atau ketik hanya dibaca di browsermu sendiri. Tidak ada data yang dikirim ke server Tamatech atau ke mana pun — tutup halaman, datanya hilang.

JSON bersarang jadi apa di CSV?

Objek bersarang diratakan jadi kolom dengan nama bertitik — misalnya alamat.jalan dan alamat.kode_pos. Nilai array diubah jadi teks JSON supaya tetap satu sel.

CSV seperti apa yang bisa diubah ke JSON?

CSV yang baris pertamanya judul kolom. Tanda kutip, koma di dalam kutip, dan baris baru di dalam kutip ditangani dengan benar. Hasilnya JSON array — satu objek per baris.

Apa bedanya Rapikan dan Padatkan?

Rapikan menulis ulang JSON dengan indent 2 spasi supaya mudah dibaca manusia. Padatkan menulis ulang jadi satu baris tanpa spasi — lebih kecil untuk dikirim atau disimpan. Isi datanya sama persis.

Seberapa besar file yang bisa diproses?

Tergantung browsermu — file sampai beberapa MB (puluhan ribu baris) umumnya lancar karena pemrosesan dilakukan bertahap. Pratinjau di halaman dibatasi 50 baris pertama, tapi file unduhan berisi seluruh hasil.
