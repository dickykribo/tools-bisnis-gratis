# Tools Bisnis Gratis — Tamatech

Kumpulan tools bisnis kecil gratis untuk UMKM Indonesia: kalkulator, generator dokumen,
dan alat file. Dibangun oleh [Tamatech](https://tamatech.id) (Tama Technology, Bandung).

Semua tool berjalan sepenuhnya di browser — gratis, tanpa daftar, tanpa iklan, dan data
yang kamu isi tidak dikirim atau disimpan di mana pun.

## Cara pakai

Buka file `tools/<nama-tool>/index.html` di browser. Tidak butuh server, tidak butuh
instalasi apa pun. Versi live (dengan tampilan situs Tamatech) ada di
[https://tamatech.id/tools](https://tamatech.id/tools).

## Struktur repo

```
.
├── README.md
├── LICENSE
├── assets/
│   ├── tools.css          # gaya bersama semua tool (tema terang)
│   ├── xlsx.js            # SheetJS 0.18.5 (Apache 2.0) — baca/tulis Excel
│   ├── jsbarcode.js       # JsBarcode 3.11.6 (MIT) — render barcode
│   └── qrcode.js          # qrcode-generator (MIT) — render QR code
└── tools/
    └── <slug>/
        └── index.html     # satu file per tool, bisa dibuka langsung
```

Tiap tool adalah satu file `index.html` mandiri: markup + gaya + logika hitung di dalam
file itu sendiri, ditambah `assets/tools.css` dan — bila perlu — satu library di atas.
Tidak ada build step, tidak ada backend, tidak ada pelacakan.

## Catatan

- Hasil kalkulator gaji, lembur, dan THR adalah **estimasi** — aturan PPh 21, BPJS, dan
  UU Ketenagakerjaan bisa berubah, dan hasil di sini bukan nasihat hukum atau pajak.
- Fee marketplace pada Kalkulator Biaya Marketplace adalah angka contoh — fee berbeda
  per kategori dan sering berubah; cek ketentuan marketplace yang bersangkutan.
- Tools ini adalah versi statis dari halaman yang sama di situs Tamatech. Tampilan di
  sini lebih sederhana (tanpa header, tema gelap, dan widget situs) — fungsinya sama.
